Managed App Deployment Tool

Sign in, pick a source environment and app, pick a target environment, then click Deploy App. Environments and apps are pulled live from your Power Platform tenant.

All environment/app/solution lookups and the deploy itself run as this account. Pick one cached below, or click "Sign in (new account)" if you need an account that isn't listed.

Requirements

Click Check Requirements after picking a source app and target environment to see what Dataverse tables and connections this app needs.

Optionally install a solution from the source environment into the target before deploying — useful if this app needs Dataverse tables, or if the solution carries along other components (flows, plugins, etc.) this tool can't otherwise detect. Skip if nothing extra is needed.
